Visual Automasi AI Agent (Workflow Architecture)

Gambaran alur kerja bagaimana mesej pengguna diproses dari Telegram ke AI Agent dan disimpan ke pangkalan data.

STEP 1: TRIGGER

Telegram Webhook

Menerima mesej yang dihantar oleh pengguna dari aplikasi Telegram melalui API BotFather.

POST /telegram/webhook
STEP 2: AI AGENT

Gemini / OpenAI Engine

Menganalisis teks, merujuk System Prompt & konteks, lalu menjana jawapan pintar automatik.

model: gemini-2.5-flash
STEP 3: LOG & STORAGE

Google Sheets / Database

Menyimpan log perbualan, maklumat pelanggan, dan analisa sentimen secara automasi.

Append Row (Date, User, Msg)
STEP 4: RESPONSE

Hantar Respon Telegram

Menghantar jawapan yang terhasil terus ke skrin ruang sembang pengguna Telegram.

sendMessage(chat_id, text)

Panduan Ringkas Penyediaan Make.com (No-Code):

  1. Buka akaun di Make.com dan cipta Scenario baharu.
  2. Tambah modul Telegram Bot -> Watch Updates dan masukkan API Token daripada @BotFather.
  3. Sambungkan ke modul OpenAI / Google Gemini dan masukkan prompt Sistem anda.
  4. Tambah modul Telegram Bot -> Send a Message untuk membalas mesej semula ke Telegram.

Skrip Python Lengkap (Ready-to-Deploy)

Kod ini dihasilkan secara automatik mengikut tetapan nama bot dan System Prompt anda!

# Skrip Python sedang dijana...

1. Pasang Library Required

Jalankan perintah ini di Command Prompt / Terminal anda:

pip install pyTelegramBotAPI google-generativeai

2. Dapatkan API Key

Dapatkan Telegram Token daripada Telegram @BotFather dan API Key percuma daripada Google AI Studio.

3. Jalankan Skrip

Simpan kod di atas sebagai bot.py dan jalankan menerusi perintah python bot.py.
